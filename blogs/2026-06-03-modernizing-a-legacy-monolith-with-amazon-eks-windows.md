Tipalti, a payables automation platform, containerized a legacy .NET Framework 4.7 monolithic application and migrated it from Amazon EC2 to Amazon EKS with Windows Server nodes, achieving a 50% performance improvement and 60% cost reduction. Key challenges addressed included graceful shutdown handling, logging transformation, event-driven autoscaling with KEDA, and networking issues specific to Windows containers.
